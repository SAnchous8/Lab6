# Задание 1

### Текст задачи

Разработать класс с тремя целочисленными полями. Создать конструктор копирования. Разработать метод, вычисляющий максимальную из последних цифр полей. Перегрузить метод ToString() для формирования строки из полей класса. Реализовать дочерний класс (его содержание предложить самостоятельно и описать в решении: какой содержательный смысл имеют поля; реализовать конструкторы; предложить и реализовать 2-3 метода). Протестировать все конструкторы и другие методы базового и дочернего классов.

### Алгоритм решения

1. Создание вспомогательного метода ReadInt(string message)

Назначение: Безопасное чтение целого числа с консоли с обработкой ошибок ввода.

Алгоритм работы:

Запустить бесконечный цикл.
Вывести сообщение-приглашение message.
Считать строку с консоли (Console.ReadLine()).
Проверить, что строка не null и не пустая:
Если пустая — вывести сообщение об ошибке и перейти к следующей итерации цикла.
Попытаться преобразовать строку в целое число через int.TryParse():
Если успешно — вернуть полученное число и выйти из метода.
Если неуспешно — вывести сообщение об ошибке и перейти к следующей итерации цикла.

2. Создание базового класса ThreeNumbers

Поля: Три приватных целочисленных поля (number1, number2, number3).

Конструкторы:

По умолчанию: Инициализирует поля нулями.
С параметрами: Принимает 3 целых числа, присваивает их полям.
*Копирования: * Принимает объект класса ThreeNumbers, копирует значения его полей в поля текущего объекта.
Свойства: Number1, Number2, Number3 с аксессорами get и set.

Метод GetMaxLastDigit():

Вычислить абсолютное значение последней цифры для каждого числа: Math.Abs(number % 10).
Найти максимальное значение среди трёх полученных цифр.
Вернуть максимальную цифру.
Переопределение метода ToString():

Сформировать и вернуть строку вида "Numbers: X, Y, Z".

3. Создание дочернего класса Triangle

Содержательный смысл полей: Унаследованные поля — длины сторон треугольника A, B, C.

Конструкторы:

По умолчанию: Вызывает base(1, 1, 1) — создаёт равносторонний треугольник.
С параметрами (int a, int b, int c):
Вызывает base(a, b, c).
Выполняет валидацию через IsValidTriangle(): проверяет положительность сторон и неравенство треугольника.
При нарушении выводит предупреждение.
Копирования: Вызывает base(other).

Методы класса Triangle:

GetPerimeter(): Возвращает Number1 + Number2 + Number3.
GetArea(): Вычисляет площадь по формуле Герона через полупериметр.
IsRightTriangle(): Проверяет теорему Пифагора для всех трёх комбинаций сторон.
Переопределение метода ToString():

Возвращает строку вида "Triangle: A = X, B = Y, C = Z".

4. Тестирование в методе Main()

Часть 1: Тестирование базового класса ThreeNumbers

Вывести заголовок "=== ТЕСТ ТРЁХ ЧИСЕЛ ===".
Вызвать ReadInt() трижды для ввода чисел n1, n2, n3.
Создать объект obj класса ThreeNumbers с введёнными значениями.
Вывести информацию об объекте через неявный вызов obj.ToString().
Вызвать и вывести результат obj.GetMaxLastDigit().
Создать объект copy — копию obj через конструктор копирования.
Вывести информацию об объекте-копии.
Вызвать ReadInt() для ввода нового значения первого числа.
Присвоить новое значение через свойство obj.Number1.
Вывести обновлённую информацию об объекте и новое значение максимальной последней цифры.

Часть 2: Тестирование дочернего класса Triangle

Вывести заголовок "=== ТЕСТ ТРЕУГОЛЬНИКА ===".
Вызвать ReadInt() трижды для ввода длин сторон a, b, c.
Создать объект tri класса Triangle с введёнными значениями (при некорректном вводе сработает валидация).
Вывести информацию о треугольнике.
Вызвать и вывести:
Периметр (tri.GetPerimeter())
Площадь (tri.GetArea())
Проверить через tri.IsRightTriangle() прямоугольность треугольника и вывести соответствующий результат.
Продемонстрировать наследование: вызвать tri.GetMaxLastDigit() и вывести результат.
Завершение программы:

Ожидать нажатия клавиши (Console.ReadKey())

# Задание 2

### Текст задачи

LineSegment
double x, double y

(координаты начала и конца отрезка на координатной прямой)

Определить, попадает ли заданное число в отрезок. Результат должен быть типа bool.

Унарные операции:

! - вычислить длину отрезка, результат должен быть типа double;

++ увеличить координаты границ отрезка на 1.

Операции приведения типа:

int (явная) – результатом является целая часть координаты х;

double (неявная) – результатом является координата y.

Бинарные операции:

+int d, целое число (лево- и правосторонняя операция, координаты границ увеличиваются на число d);

< LineSegment, целое число – результат равен true, если целое число попадает в заданный отрезок и false–в противном случае.

### Алгоритм решения

1. Создание вспомогательных методов для безопасного ввода

Метод ReadDouble(string message):

Запустить бесконечный цикл.
Вывести сообщение-приглашение message.
Считать строку с консоли.
Проверить через string.IsNullOrEmpty(), что строка не пустая:
Если пустая → вывести ошибку и продолжить цикл.
Заменить точку на запятую (Replace('.', ',')) для корректного парсинга.
Попытаться преобразовать строку в double через double.TryParse():
Успешно → вернуть число.
Ошибка → вывести сообщение и повторить ввод.

Метод ReadInt(string message):

Аналогичен ReadDouble, но:
Не заменяет точку на запятую.
Использует int.TryParse().

2. Создание класса LineSegment

Поля: Два приватных поля double start и double end — координаты начала и конца отрезка.

Конструкторы:

По умолчанию: Инициализирует start = 0, end = 1.
С параметрами (double x1, double x2):
Если x1 < x2 → start = x1, end = x2.
Иначе → start = x2, end = x1 (автоматическое упорядочивание).
Копирования: Копирует start и end из другого объекта.
Свойства:

Start:
get — вернуть start.
set — если value ≤ end → start = value. Иначе → start = end, end = value.
End:
get — вернуть end.
set — если value ≥ start → end = value. Иначе → end = start, start = value.
Length (только для чтения): вернуть end - start.
Методы:

Contains(double number): вернуть true, если number находится между start и end включительно.
Equals(object obj): сравнить текущий объект с другим по значениям start и end.
GetHashCode(): вернуть XOR хеш-кодов полей start и end.
Переопределение ToString(): Вернуть строку вида "[start, end] длина = Length".

3. Перегрузка операторов в классе LineSegment

Унарные операторы:

! (логическое отрицание):
Смысл: вычислить длину отрезка.
Алгоритм: вернуть значение свойства Length.
++ (инкремент):
Смысл: увеличить обе координаты на 1.
Алгоритм: увеличить start и end на 1, вернуть текущий объект.
Операторы приведения типа:

Явное приведение к int — explicit operator int(LineSegment seg):
Смысл: получить целую часть координаты начала отрезка.
Алгоритм: вернуть (int)seg.start.
Неявное приведение к double — implicit operator double(LineSegment seg):
Смысл: получить координату конца отрезка.
Алгоритм: вернуть seg.end.
Бинарные операторы:

+ (сложение с целым числом):
Левосторонний LineSegment + int d:
Создать и вернуть новый объект LineSegment с координатами start + d и end + d.
Правосторонний int d + LineSegment seg:
Вызвать левосторонний оператор: return seg + d.
< (меньше, сравнение с целым числом):
Смысл: проверить, попадает ли целое число в отрезок.
Алгоритм: вернуть результат вызова Contains(number).
> (больше, сравнение с целым числом):
Смысл: обратная проверка (число НЕ принадлежит отрезку).
Алгоритм: вернуть !(seg < number).

4. Тестирование в методе Main()

Часть 1: Создание отрезка и тест унарных операторов

Вывести заголовок "=== ТЕСТ ОТРЕЗКА С ПЕРЕГРУЗКОЙ ОПЕРАТОРОВ ===\n".
Запросить через ReadDouble() координаты x и y.
Создать объект LineSegment seg.
Вывести информацию об отрезке.
Вычислить длину через оператор !seg и вывести результат.
Вывести отрезок до ++, выполнить seg++, вывести после.

Часть 2: Тест операторов приведения типа

Выполнить явное приведение (int)seg → вывести целую часть начала.
Выполнить неявное приведение double y = seg → вывести значение конца.

Часть 3: Тест бинарного оператора +

Запросить целое число d через ReadInt().
Вычислить seg + d и сохранить в shifted1.
Вычислить d + seg и сохранить в shifted2.
Вывести оба результата (демонстрация коммутативности).

Часть 4: Тест операторов сравнения < и >

Запросить целое число testNumber через ReadInt().
Проверить if (seg < testNumber):
true → число принадлежит отрезку.
false → число не принадлежит.
Проверить if (seg > testNumber):
true → число НЕ принадлежит отрезку.
false → число принадлежит отрезку.

Часть 5: Тест конструктора копирования и метода Contains

Создать объект copy через new LineSegment(seg).
Вывести информацию о копии.
Запросить дробное число testDouble через ReadDouble().
Проверить через метод seg.Contains(testDouble) и вывести результат.
Завершение программы:

Вывести "\nНажмите любую клавишу...".
Ожидать нажатия клавиши (Console.ReadKey()).
