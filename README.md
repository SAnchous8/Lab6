# Задание 1

### Текст задачи

Разработать класс с тремя целочисленными полями. Создать конструктор копирования. Разработать метод, вычисляющий максимальную из последних цифр полей. Перегрузить метод ToString() для формирования строки из полей класса. Реализовать дочерний класс (его содержание предложить самостоятельно и описать в решении: какой содержательный смысл имеют поля; реализовать конструкторы; предложить и реализовать 2-3 метода). Протестировать все конструкторы и другие методы базового и дочернего классов.

### Алгоритм решения

### Алгоритм решения

1. Попадаем в метод Main - точку входа программы

2. Выводим заголовок "=== Тестирование ThreeNumbers ===" и пустую строку

3. Создаем объект базового класса ThreeNumbers:
   
   Считываем три числа с помощью функции ReadInt
   
   Для каждого числа выводим приглашение "Число X: "
   
   Вызываем конструктор ThreeNumbers с тремя аргументами
   
   Сохраняем объект в переменную obj

4. В функции ReadInt:
   
   Запускаем бесконечный цикл
   
   Выводим приглашение prompt
   
   Считываем строку ввода
   
   Проверяем, пустая ли строка:
   
   Если пустая, выводим "Ошибка: пустой ввод" и продолжаем цикл
   
   Пытаемся преобразовать строку в целое число с помощью int.TryParse
   
   Если преобразование успешно, возвращаем результат
   
   Если нет, выводим "Ошибка: введите целое число" и продолжаем цикл

5. Выводим объект obj на консоль

6. Создаем и выводим копию объекта с помощью конструктора копирования ThreeNumbers(obj)

7. Вызываем и выводим результат метода GetMaxLastDigit для объекта obj

8. Запрашиваем новое значение для первого числа:
   
   Выводим сообщение "Новое значение для первого числа: "
   
   Считываем число с помощью ReadInt
   
   Присваиваем его свойству FirstNumber объекта obj

9. Выводим обновленный объект и новое значение максимальной последней цифры

10. Выводим заголовок "=== Тестирование TriangleSides ===" и пустую строку

11. Создаем объект дочернего класса TriangleSides:
    
    Инициализируем переменную tri значением null
    
    Запускаем цикл, который выполняется пока tri равен null
    
    Считываем три числа - стороны треугольника
    
    Пытаемся создать объект TriangleSides с этими сторонами
    
    Если конструктор выбрасывает исключение ArgumentException:
    
    Выводим сообщение об ошибке и продолжаем цикл
      
    Если исключения нет, объект успешно создан и цикл завершается

12. В конструкторе TriangleSides:
    
    Вызываем конструктор базового класса ThreeNumbers с переданными сторонами
    
    Проверяем условие существования треугольника:
    
    Все стороны больше нуля
    
    Сумма любых двух сторон больше третьей
    
    Если условие не выполняется, выбрасываем исключение ArgumentException

13. Выводим информацию о треугольнике:
    
    Сам объект tri
    
    Копию объекта с помощью конструктора копирования TriangleSides(tri)
    
    Периметр - вызов метода CalculatePerimeter
    
    Площадь - вызов метода CalculateArea с форматированием до двух знаков
    
    Проверку на прямоугольность - вызов метода IsRightAngled
    
    Максимальную последнюю цифру сторон - вызов метода GetMaxLastDigit (унаследован от ThreeNumbers)

14. В методе CalculatePerimeter:
    
    Возвращаем сумму трех сторон (FirstNumber, SecondNumber, ThirdNumber)

15. В методе CalculateArea:
    
    Вычисляем полупериметр p = периметр / 2.0
    
    Возвращаем квадратный корень из p*(p-a)*(p-b)*(p-c)

16. В методе IsRightAngled:
    
    Вычисляем квадраты сторон
    
    Проверяем, выполняется ли теорема Пифагора для любой комбинации

17. Выводим сообщение "Нажмите любую клавишу..." и ожидаем нажатия клавиши

18. Завершаем программу

# Задание 2

### Текст задачи

LineSegment
double x, double y

(координаты начала и конца
отрезка на координатной
прямой)

Определить, попадает ли заданное число
в отрезок. Результат должен быть типа
bool.

Унарные операции:
! - вычислить длину отрезка, результат должен быть типа double;
++ увеличить координаты границ отрезка на 1.

Операции приведения типа:
int (явная) – результатом является целая часть координаты х;
double (неявная) – результатом является координата y.

Бинарные операции:
+int d, целое число (лево- и правосторонняя операция, координаты границ
увеличиваются на число d);
< LineSegment, целое число – результат равен true, если целое число
попадает в заданный отрезок и false–в противном случае.


### Алгоритм решения

### Алгоритм решения

1. Попадаем в метод Main - точку входа программы

2. Выводим заголовок "=== ТЕСТИРОВАНИЕ LineSegment ===" и пустую строку

3. Создаем объект класса LineSegment:
   
   Считываем первую координату с помощью ReadDouble
   
   Считываем вторую координату с помощью ReadDouble
   
   Вызываем конструктор LineSegment с двумя аргументами
   
   Сохраняем объект в переменную s
   
   Выводим созданный отрезок

4. В функции ReadDouble:
   
   Запускаем бесконечный цикл
   
   Выводим приглашение prompt
   
   Считываем строку ввода
   
   Проверяем, пустая ли строка - если пустая, выводим ошибку и продолжаем
   
   Заменяем точку на запятую во введенной строке
   
   Пытаемся преобразовать строку в число с плавающей точкой
   
   Если успешно, возвращаем результат
   
   Если нет, выводим ошибку и продолжаем

5. В конструкторе LineSegment:
   
   Принимаем два числа x1 и x2
   
   Находим минимальное значение - присваиваем startX
   
   Находим максимальное значение - присваиваем endX

6. Вычисляем и выводим длину отрезка с помощью унарного оператора !
   
   Вызываем оператор !s, который возвращает длину (endX - startX)

7. Демонстрируем работу унарного оператора ++:
   
   Выводим текущее состояние отрезка
   
   Выполняем s++, который увеличивает startX и endX на 1
   
   Выводим измененный отрезок

8. Демонстрируем явное и неявное приведение типов:
   
   Выводим (int)s - явное приведение к int, возвращает целую часть startX
   
   Выводим (double)s - неявное приведение к double, возвращает значение endX

9. Демонстрируем бинарный оператор + с целым числом:
   
   Считываем целое число d с помощью ReadInt
   
   Выводим результат s + d (левосторонний оператор)
   
   Выводим результат d + s (правосторонний оператор)
   
   В обоих случаях создается новый отрезок со смещенными границами

10. В операторах +:
    
    Левосторонний: принимает отрезок и целое число, возвращает новый отрезок с startX+d и endX+d
    
    Правосторонний: принимает целое число и отрезок, вызывает левосторонний оператор

11. Демонстрируем операторы < и >:
    
    Считываем целое число test с помощью ReadInt
    
    Выводим результат s < test - проверяет, входит ли число в отрезок
    
    Выводим результат s > test - возвращает отрицание от s < test
    
    Выводим текстовое пояснение: принадлежит число отрезку или нет

12. В операторе <:
    
    Вызываем метод Contains, который проверяет, находится ли значение между startX и endX включительно

13. Выводим сообщение "Нажмите любую клавишу..." и ожидаем нажатия клавиши

14. Завершаем программу
